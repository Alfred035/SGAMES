# 🎮 SGAMES

**SGAMES** é um projeto de site de e-commerce fictício voltado para o universo gamer, desenvolvido como projeto acadêmico com **HTML, CSS e JavaScript**.

A proposta do projeto é simular uma loja virtual de produtos gamers, apresentando jogos, consoles, acessórios e ofertas em uma interface moderna e responsiva.

## 📌 Sobre o projeto

O site foi desenvolvido para praticar conceitos de **desenvolvimento web**, organização de páginas, estilização com CSS e implementação de funcionalidades utilizando JavaScript.

A SGAMES possui diferentes categorias de produtos e uma estrutura semelhante à de uma loja virtual, com navegação entre páginas, catálogo de produtos, preços, promoções e área de contato.

## 🚀 Funcionalidades

* Página inicial com produtos em destaque
* Catálogo de jogos
* Catálogo de consoles
* Catálogo de acessórios gamers
* Seção de promoções
* Carrossel automático de banners
* Barra de pesquisa visual
* Área de contato
* Formulário de contato
* QR Code para contato via WhatsApp
* Navegação entre as páginas
* Efeitos de interação nos produtos
* Layout adaptável para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para estruturar as páginas e organizar o conteúdo do site.

### CSS3

Responsável pela estilização, layout, cores, tipografia, cards, efeitos de interação e responsividade.

### JavaScript

Utilizado principalmente para implementar o funcionamento do carrossel automático de banners.

### Google Fonts

Utilização das fontes **Rajdhani** e **Nunito** para a identidade visual do projeto.

## ▶️ Como executar

Como o projeto utiliza HTML, CSS e JavaScript sem dependências externas obrigatórias de execução, basta clonar o repositório e abrir o arquivo `index.html` no navegador.

```bash
git clone https://github.com/seu-usuario/SGAMES.git
```

Depois, abra:

```text
index.html
```

Também é possível utilizar extensões como **Live Server** no Visual Studio Code para executar o projeto localmente.
